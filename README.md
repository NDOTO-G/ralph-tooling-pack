# Ralph Tooling Research Pack

This research pack gathers all notes, findings, prompts, scripts, comparison tables and references produced during our exploration of Ralph loops and three major agent runtimes—**OpenCode**, **Codex CLI** and **Claude Code**.  The goal is to provide a comprehensive offline resource for building and refining a Ralph harness.  The pack is organised into numbered sections with their own subfolders:

* **10_RALPH_CORE/** contains summaries of Ralph concepts, primitives, failure modes, validation/back‑pressure techniques and stop conditions, along with reference prompts.
* **20_OPENCODE/**, **30_CODEX/** and **40_CLAUDE_CODE/** each contain overviews, tools inventories, skills or prompting patterns, hooks, stop/budget guidance, best‑practice playbooks, example workflows and sample prompts for the corresponding runtime.
* **50_COMPARISONS/** consolidates cross‑tool matrices, equivalence maps and architectural recommendations.
* **60_SCRIPTS_AND_TEMPLATES/** holds reusable prompt templates, shell scripts and JSON schemas used by the harness.
* **70_SOURCES/** lists all external documentation and blog posts cited in the research.

Use the **00_INDEX/00_TABLE_OF_CONTENTS.md** to locate specific files.  The **MANIFEST.txt** enumerates every file in this pack, while **CHECKSUMS.sha256** provides hashes for integrity verification.  No new research has been added; all content reflects the materials produced or referenced during the project.
